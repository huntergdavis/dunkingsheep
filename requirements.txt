# Dunking Sheep has no third-party Python dependencies.
#
# It uses only the Python standard library (curses, threading, subprocess,
# socket, json) and shells out to the `herdr` CLI, which must be installed
# separately and have a running server. The MCP server is also stdlib-only.
#
# Requirements:
#   - Python 3.8+
#   - herdr 0.7.4+ (with a running server) on PATH or at ~/.local/bin/herdr
