## Known limitations

- Long free-text memory queries are slower (intent p95 4192.96 ms) because they match many chunks; session-start context and harness/project-filtered recall are fast (p50 ~17 ms here).
- Deja's index here is the rebuilt ~67 MB index; coverage of older sessions may be partial.
- Golden queries are still derived from indexed text; the intent set is hand-written to counter that, at the cost of a small sample.
