usage: dunkingsheep worktrees [-h] <subcommand> ...

positional arguments:
  <subcommand>
    disk        read-only report: size, age, pull request and build caches of
                each directory
    inventory   read-only: every worktree of the repository with its class,
                build caches and why the cleaner keeps each
    scratch     read-only: this project's test and tool leftovers in /tmp, by
                prefix, with age, size and whether held open
    clean       delete merged worktrees' Cargo build caches; a dry run unless
                --apply

options:
  -h, --help    show this help message and exit
