usage: dunkingsheep secrets-check [-h] [--base BASE] [--cwd CWD] [--quiet]

Exits 1, with a named refusal, when this branch ADDS a path that must never
leave the host (data/, *.sqlite3, *-credentials, *.pem, *token*, .env). Called
by the git credential helper and by the gh wrapper before `gh pr create`
(t756).

options:
  -h, --help   show this help message and exit
  --base BASE  diff against this ref (default: origin/main)
  --cwd CWD    repository to check (default: cwd)
  --quiet
